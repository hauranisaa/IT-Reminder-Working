# IT Task & Reminder Dashboard

Dashboard task, reminder, dan weekly recap (React + Vite + Tailwind). Data tersimpan di `localStorage` browser.

## Jalankan lokal

```bash
npm install
npm run dev
```

## Deploy ke GitHub Pages

1. Buat repo baru di GitHub, lalu push project ini ke branch `main`.
2. Di repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Setiap push ke `main` otomatis build dan deploy. Alamatnya: `https://<username>.github.io/<nama-repo>/`
